# line_editor — レーシングラインを手で引く（L0。制御コードは変えない）

| すること | やり方 |
|---|---|
| 開く | `line_editor.html` をブラウザで開く（サーバー不要。`data.js` が同じ場所に要る） |
| 動かす | 点をドラッグ。まわりの点も一緒に動く（範囲は上のスライダー、0 にするとその点だけ）。背景をドラッグで地図の移動、ホイールで拡大 |
| 足す・消す・戻す | 線の上でダブルクリック／点を右クリック／Ctrl+Z |
| 補助円（半径を知る） | 「補助円を置く」を押し、地図を3回クリック → 3点を通る円と半径（m）・曲率（1/m）が出る。■ をドラッグで動かす、■ を右クリックで円を消す。いくつでも置ける。線にも CSV にも入らない |
| 帯の外を見る（赤） | 制御器がならした後の線が帯（壁から `width ÷ √2` の内側）に無い所に赤い丸が出る。下の行に「帯の外 N 点」。点を動かすとその場で変わる |
| 円弧と直線で引く | 補助円を、走る所に3点ずつ置いていく（置く順は自由）。「補助円をつないで線にする」に印 → 円弧と、となりの円への接線（直線）でできた線に置きかわる。■ を動かすと線もその場で変わる。○ が円弧の始まり・終わり。印の間は線の点を動かせない。印を外すと、その線が点の列として残り、点で直せる。Ctrl+Z で印を付ける前の線に戻る |
| 円弧の表 | 「円弧の表を書き出す」→ `arcs_hand_日時.csv`（円ごとに1行: 向き、半径、中心、円弧の始まり・終わりの場所と道のり、次の円までの直線の長さ、補助円の3点）。「続きから」で読み込むと補助円が戻る |
| 書き出す | 「CSV を書き出す」→ ブラウザの保存先に `traj_hand_日時.csv`。続きは「続きから」でその CSV を読み込む |
| 確かめる | `./check_line.sh <csv>`（コンテナ内で制御器の `load_ref_path`・`Map`・`ReferencePath` を使い、ならした後の線が帯の内側かを出す。走行中は動かない） |
| 地図か元の線を差し替えたら | `python3 make_data.py` で `data.js` を作り直す |

- 始まりは `env/final_ver3/traj_mincurv.csv` の点そのまま。触らない点の `x_m`・`y_m` は元のファイルと同じ文字列で出る。
- 出す列は `s_m, x_m, y_m, psi_rad, kappa_radpm`。制御器が使うのは `x_m`・`y_m` だけ（`core/utils.py` の `load_ref_path`、`mpc_controller.py` の読み込み行）。`s_m`・`psi_rad`・`kappa_radpm` は点から計算し直すので、元のファイルの値とは少し違う。`vx_mps`・`ax_mps2` は出さない。
- 画面の白い所（壁のマスの中心から `width ÷ √2` 以上）は線に関係なく引ける目安。制御器は線の法線の向きに壁までを測るので、判定は `check_line.sh` の出力を使う。
- 赤い丸は、制御器の手順（`core/reference_path.py` の `_construct_path`・`_compute_width`・`_get_min_width` と skimage の `line_aa`）を画面の中でまねた計算。2026-11-17 に4本の線（元の線、手で引いた線、試験用2本）で制御器の値と点ごとに照合し、点の数と帯の外の点が同じ、帯の端の差は 1e-15 m 以下だった（照合のスクリプトと出力はリポジトリに入れていない）。制御器のコードか `config.yaml` の `reference_path` が変わったら合わなくなるので、判定は `check_line.sh` を使う。
- 円弧の線の決まり: 円の順番と曲がる向き（左・右）は、円の2点目にいちばん近い「今の線」（灰色）の場所と、そこでの進む向きで決まる（ラベルに `#番号 左曲がり／右曲がり` と出る）。点は1周を約 1 m ごとに等分して置く（今の線の平均 1.0 m に合わせた）。始点は今の線の始点にいちばん近い点。
- つながらない組は赤い字で出て、線は前のまま: 逆向きの円どうしは重なると接線が引けない。同じ向きの円どうしは片方がもう片方の中に入ると引けない。「あと何 m 離す」が出る。円弧が一回りしたときも赤い字で出る。
- 補助円は `traj_hand_日時.csv` には入らない。円を残すには円弧の表も書き出す。
- 書き出した線を制御器に使わせるには `config.yaml` の `csv_path` を変える。これは L3 の実験で、タスクカードが要る。下書きは `drafts/` に置く。
- `check_line.sh` は、ビルド済みのチェックアウト以外（worktree など）から使うとき `RACINGKART_DIR=<ビルド済みの aichallenge-racingkart>` を付ける。
